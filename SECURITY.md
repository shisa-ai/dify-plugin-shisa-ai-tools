# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed credential.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/shisa-ai/dify-plugin-shisa-ai-tools/security/advisories/new

Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include real API keys, Dify application tokens, user data, or remote-debug credentials in the report.

## Supported versions

Security fixes are applied to the latest released plugin version. Users should upgrade to the newest GitHub Release and confirm current API and platform information through the official Shisa documentation.
